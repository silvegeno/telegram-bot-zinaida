# «Ироничная секретарша» — Telegram-бот трекер задач

## Состояние проекта (2026-07-29)

- **Стек:** Python 3.14, aiogram 3, APScheduler, CSV-хранилище, VseLLM API для AI-комментариев
- **Запуск:** `venv/Scripts/activate` → `python bot.py`
- **Конфиг:** `.env` (токен бота, owner ID, ключ vsellm)
- **Статус:** код написан и скомпилирован (7 модулей), venv настроен, зависимости установлены, **не запущен** (нет `.env` с реальным токеном)

## Модули

| Файл | Назначение |
|---|---|
| `bot.py` | Главный диспетчер: FSM-состояния, хендлеры команд и inline-кнопок |
| `config.py` | Загрузка `.env` |
| `csv_storage.py` | CRUD для tasks.csv, recurring_tasks.csv, profile.csv |
| `keyboards.py` | Reply + inline клавиатуры |
| `scheduler.py` | APScheduler: напоминания за час (раз в минуту) + ежедневная рассылка в 10:00 |
| `phrases.py` | 7 категорий встроенных ироничных фраз (fallback) |
| `ai_comments.py` | Генерация через VseLLM (`/v1/chat/completions`, OpenAI-совместимый) |

## Реализовано

- `/start`, `/menu`, `/help`, `/profile` (уровни 1–4)
- `/add` — разовая задача с проверкой даты и времени
- `/add_regular` — daily / weekly (по дням недели) / interval_days (2–30)
- `/tasks` + inline-кнопки ✅ Выполнить / ❌ Отменить
- `/regular` + ✅ Выполнено
- Защита от повторной награды
- Доступ только для owner по TELEGRAM_OWNER_ID
- AI-комментарии через vsellm.ru, fallback на встроенные фразы
- Повышение уровня с отдельным поздравлением

## Что доделать

1. Создать `.env` с реальным `TELEGRAM_BOT_TOKEN`
2. Запустить и протестировать все сценарии
3. При необходимости добавить screen/systemd для VPS
