Зинаида

Строгая, но добрая секретарша в вашем Telegram

Трекер задач с ироничными комментариями и геймификацией. Зинаида ведёт вашу картотеку дел, напоминает о дедлайнах и хвалит за продуктивность — умеренно.

Открыть в Telegram

Возможности

  • 📝 Разовые задачи с дедлайном
  • 🔁 Регулярные: каждый день, раз в неделю, раз в N дней
  • ✅ Отметка выполнения — очки в копилку
  • ⏰ Напоминание за час до дедлайна
  • 📋 Ежедневная сводка регулярных заданий в 10:00
  • 🤖 AI-комментарии от Зинаиды
  • 🔒 Доступ только для владельца
  • 📊 Профиль, очки, уровни

Как устроена

🐍 Python 3.14

aiogram 3 для Telegram API, APScheduler для напоминаний, CSV вместо базы данных.

🧠 AI-комментарии

Зинаида подключается к нейросети через VseLLM API и комментирует ваши успехи (и не только).

💾 CSV-хранилище

Никаких баз данных — tasks.csv, recurring_tasks.csv и profile.csv. Просто, надёжно, как картотека.

📡 VPS-ready

Готов к деплою на любой VPS через screen или systemd. Зависимости — четыре пакета.

Зинаида не забывает. Зинаида всегда рядом.
